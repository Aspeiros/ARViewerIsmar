# Media Repository - ISMAR 2026 WebAR

Questa cartella raccoglie tutte le risorse multimediali per l'esperienza AR, suddivise per tipologia:

## Struttura
- `3d_models/`: Modelli tridimensionali (.glb consigliato, possibilmente sotto i 15MB).
- `animations/`: Clip animate o video (.mp4 H.264 / .webm).
- `images/`: Immagini, cartelli, foto informative (.webp, .png, .jpg).
- `markers/`: File target per il tracking (file .mind per MindAR, .patt o immagini sorgente).
- `audio/`: Tracce vocali, audioguide o effetti sonori (.mp3, .m4a).

I file inseriti qui e sincronizzati su GitHub sono accessibili all'URL:
`https://aspeiros.github.io/ARViewerIsmar/media/<cartella>/<nomefile>`
